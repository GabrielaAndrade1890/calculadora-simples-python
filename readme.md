# Calculadora Simples
 Projeto de uma calculadora simples feita no Python. Seu objetivo principal visa calcular operações simples e resolve-las rapidamente.
<br>
<br>

 # Operações que estará presente neste projeto
    - Soma;
    - Subtração;
    - Multiplicação;
    - Divisão.
<br>
<br>

# Como usar? Tutorial rápido
    > 1. Primeiro digite o primeiro número:
        (ex: Digite o primeiro número: 10)

    > 2. Em seguida digite o segundo número:
        (ex: Digite o segundo número: 8)

    > 3. Depois digite qual operação básica você prefere e o resultado aparecerá logo em seguida
